## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦 (Status Quo)**：高亮散落在不同工具、样式单一（只有黄色）、无法给一段话附笔记；AI 解读看完即忘，无法与原文绑定回看。
- **用户雇佣任务 (JTBD)**：`When` 我读到重点或得到一段有用的 AI 解读，`I want to` 用合适的样式标注它并写下自己的边注，`so I can` 在统一列表里回顾全部重点。
- **惊喜时刻 (Aha Moment)**：7 种样式 × 调色板随手即用；AI 卡片 `[存为边注]` 一键把洞察钉回原段落。
- **冷启动体验 (FTUE)**：划词胶囊里的 `[高亮]` 即是零门槛入口；任一标注都能在"标注管理"里集中看到。

## 2. 交互形态比选与取舍 (Approaches & Trade-offs)

| 评估维度 | 方案 A（推荐采纳） | 方案 B（备选弃用） | 取舍理由 (Trade-off Rationale) |
|---|---|---|---|
| **样式丰富度** | 7 样式（下划线/波浪线/加粗/斜体/删除线/半高亮/高亮）× 调色板（开发者保留） | 仅单一黄色高亮 | 满足不同语义标注（重点/疑问/引用/删除）的精细需求，是产品差异化点 |
| **批注入口** | 选中 → 调色板浮层（样式 × 颜色） | 右键菜单列全部样式 | 浮层就地、可视，减少菜单层级（希克定律） |
| **管理入口** | 顶栏 `[标注]` 打开集中管理面板 | 与目录混排 | 标注是独立资产，需独立聚合视图 |

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

| 字段/参数名 | 披露层级 | 类型 | 必填 | 校验规则与边界极端值 | 默认值与微文案提示 |
|---|---|---|---|---|---|
| `style` | 首屏必填 | 枚举 | 是 | `highlight`/`semi_highlight`/`underline`/`wavy`/`bold`/`italic`/`strike` | highlight |
| `color` | 首屏可选 | 枚举 | 是 | 调色板 6 色（黄/绿/蓝/粉/紫/橙） | 黄 |
| `anchor` | 内部 | 元组 | 是 | 字符起止偏移 + 段落索引 + 几何框 | — |
| `note_body` | 渐进折叠 | 字符串 | 否 | 0–2000 字符 Markdown | 写点什么… |
| `origin` | 内部 | 枚举 | 是 | `manual`/`companion` | manual |

### 业务分支规则矩阵
1. **分支 1（新建标注）**：选区 + 样式 + 颜色 → 写入并与段落锚点绑定，正文即时呈现该样式。
2. **分支 2（编辑边注）**：点击已有标注 → 打开边注编辑器 → 更新（`annotation.update`，事件用过去分词）。
3. **分支 3（重叠标注）**：与已有标注重叠 → 以最新样式覆盖重叠区间，不产生重叠脏区间。
4. **分支 4（AI 存为边注）**：`origin=companion`，重复归档幂等。
5. **分支 5（删除）**：从管理面板或就地删除 → 二次确认 → 软删除（`is_del`）。

### 4.2 行为驱动产品验收场景 (Gherkin Scenarios)

```gherkin
Feature: 多维标注与边注管理

  Scenario: REQ-001 用样式与颜色创建标注 (Happy Path)
    Given 用户选中了一段文本
    When 用户在调色板选择「下划线 + 蓝色」
    Then 正文该段落以内联下划线蓝色样式呈现
    And 标注与该段落的字符锚点精确绑定

  Scenario: REQ-003 AI 洞察存为边注幂等 (Happy Path)
    Given 一个伴读卡片带有内容
    When 用户点击卡片上的「存为边注」
    Then 生成一条来源为 AI 的边注并绑定到该段落
    And 再次点击不会产生重复边注

  Scenario: REQ-002 边注编辑持久化 (Happy Path)
    Given 用户对某标注已有边注
    When 用户编辑边注内容并保存
    Then 重开文档后边注内容与锚点均保持正确

  Scenario: REQ-005 重叠标注无脏区间 (Edge)
    Given 某段已有高亮标注
    When 用户对重叠区间新建下划线标注
    Then 重叠区以最新样式覆盖，不产生重叠或错位脏区间
```
