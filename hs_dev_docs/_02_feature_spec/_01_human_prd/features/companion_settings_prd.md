## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦 (Status Quo)**：本地优先阅读器若无模型配置入口，用户面对"点了解读没反应"会困惑；把密钥硬编码又不可维护、有泄漏风险。
- **用户雇佣任务 (JTBD)**：`When` 我想启用 AI 伴读或更换模型，`I want to` 在一个极简对话框里填写端点/密钥/模型并一键测试，`so I can` 立刻开始在线伴读或明确知道为何离线。
- **惊喜时刻 (Aha Moment)**：填入 3 项 + 点"测试连接"，**1 次**得到绿色连通反馈，返回阅读即可用。
- **冷启动体验 (FTUE)**：首次点击伴读模板时自动引导至此；提供"跳过，使用离线摘要"选项，永远不阻断阅读。

## 2. 交互形态比选与取舍 (Approaches & Trade-offs)

| 评估维度 | 方案 A（推荐采纳） | 方案 B（备选弃用） | 取舍理由 (Trade-off Rationale) |
|---|---|---|---|
| **配置入口** | 极简模态对话框（Base URL / API Key / Model / 测试连接） | 独立设置页跳转 | 保持阅读上下文；模态就地完成，返回即用 |
| **密钥处理** | 本地加密存储、输入框掩码、永不回显明文 | 明文存 JSON | 隐私红线；避免肩窥与日志泄漏 |
| **连通性** | 显式"测试连接"按钮 + 状态徽标 | 静默后台探测 | 用户可控、反馈明确，避免意外出站请求 |

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

| 字段/参数名 | 披露层级 | 类型 | 必填 | 校验规则与边界极端值 | 默认值与微文案提示 |
|---|---|---|---|---|---|
| `base_url` | 首屏必填 | 字符串 | 是 | 合法 http(s) URL；长度 ≤ 300 | https://api.openai.com/v1 |
| `api_key` | 首屏必填 | 字符串（密钥） | 是 | 长度 ≥ 8；掩码显示 `sk-****` | 请输入 API Key |
| `model` | 首屏必填 | 字符串 | 是 | 长度 1–100 | gpt-4o-mini |
| `temperature` | 渐进折叠 | 数字 | 否 | 0.0–2.0 | 0.7 |
| `timeout_ms` | 渐进折叠 | 整数 | 否 | 1000–120000 | 30000 |
| `max_retries` | 渐进折叠 | 整数 | 否 | 0–5 | 3 |
| `conn_status` | 首屏可见 | 枚举 | 是 | `unknown`/`testing`/`ok`/`fail` | unknown |

### 业务分支规则矩阵
1. **分支 1（测试成功）**：返回 2xx → 状态徽标置 `ok`（成功绿），保存按钮可用。
2. **分支 2（测试失败）**：非 2xx/超时 → `fail`，给出"原因 + 修复建议"（如"端点不可达，请检查 URL 与网络，或改用离线摘要"）。
3. **分支 3（必填缺失）**：提交时原位红框 + 具体提示，保留已填内容。
4. **分支 4（保存）**：原子写入本地配置（密钥加密），立即对伴读生效，无需重启。
5. **分支 5（用户撤回/跳过）**：关闭对话框不改动原配置；提供"跳过，使用离线摘要"，阅读不阻断。

## 4. 需求原子分解与行为驱动验收标准 (Requirements & Functional DoD)

### 4.1 核心需求原子分解清单 (Atomic Requirements Matrix)
| 需求编号 | 需求名称与规则简述 | 关联字段/动作 | 验收物理证据 | 优先级 |
|---|---|---|---|---|
| `REQ-001` | 极简对话框配置 Base URL / Key / Model | 打开设置 | 三字段 + 测试连接 + 保存，样式继承 `DESIGN.md` | P0 |
| `REQ-002` | 一键测试连接并给出明确状态 | 点击测试 | 状态徽标在超时前明确变绿/变红 + 人话提示 | P0 |
| `REQ-003` | 密钥本地加密存储、永不回显明文 | 保存后重开 | 输入框掩码，磁盘无明文密钥 | P0 |
| `REQ-004` | 必填缺失原位校验并保留草稿 | 空字段提交 | 红框 + 修复提示，已填内容保留 | P0 |
| `REQ-005` | 支持跳过并回退离线摘要 | 点击跳过 | 关闭设置，伴读走本地启发式降级 | P1 |
| `REQ-006` | 高级参数渐进折叠（温度/超时/重试） | 展开高级 | 默认收起，展开可调，有默认值 | P2 |

### 4.2 行为驱动产品验收场景 (Gherkin Scenarios)

```gherkin
Feature: LLM 连接与伴读设置

  Scenario: REQ-002 一键测试连接成功 (Happy Path)
    Given 用户已填入合法的 Base URL、API Key 与 Model
    When 用户点击「测试连接」
    Then 状态徽标显示「连接正常」（成功绿）并允许保存

  Scenario: REQ-004 必填缺失原位校验 (Validation)
    Given 用户未填写 Model
    When 用户点击「保存」
    Then Model 输入框原位红框高亮并提示「请填写模型名称，例如 gpt-4o-mini」
    And 其余已填字段 100% 保留

  Scenario: REQ-003 密钥隐私保护 (Privacy)
    Given 用户保存了 API Key
    When 用户再次打开设置对话框
    Then API Key 以掩码形式显示，绝不回显明文
    And 本地配置文件中不存在明文密钥

  Scenario: REQ-005 跳过并使用离线降级 (Error Recovery)
    Given 用户暂时不想配置 LLM
    When 用户在设置对话框点击「跳过，使用离线摘要」
    Then 对话框关闭、原配置不变
    And 此后的划词伴读走本地启发式降级，阅读不被阻断
```
