## 1. 特性洞察与核心价值界定 (Framing & Discovery)

- **现状与摩擦 (Status Quo)**：网页对话框能问，但每次都要重新粘贴上下文，且答案无法与原文段落绑定；读者事后想回看"当时对这个难点的解释"时一片空白。
- **用户雇佣任务 (JTBD)**：`When` 我选中一段并选择了解读角度，`I want to` 在一个卡片里看到逐步流出的深度解读并能就本段继续追问，`so I can` 一气呵成地弄懂它并沉淀成边注。
- **惊喜时刻 (Aha Moment)**：首字节（TTFT）< 800ms 即开始逐字流出 `[逻辑链推理 · TTFT 320ms]` 卡片；底部 `[追问本段细节...]` 一输即续，同一上下文内多轮深入。
- **冷启动体验 (FTUE)**：离线/未配置时，卡片立即给出本地启发式摘要（< 10ms），并标注降级状态，而非空白等待。

## 2. 交互形态比选与取舍 (Approaches & Trade-offs)

| 评估维度 | 方案 A（推荐采纳） | 方案 B（备选弃用） | 取舍理由 (Trade-off Rationale) |
|---|---|---|---|
| **承载容器** | 毛玻璃模态卡片（`FrostedModal`，440px）承载结果与追问 | 常驻右侧抽屉 | 模态内内容不透明、阅读性优先；避免常驻侧栏压缩版心、干扰心流 |
| **结果呈现** | 确定性流式卡片（逐字追加）+ 头部模板标签 + 右上 `[存为边注][✕收起]` | 一次性整段返回 | 流式显著降低等待焦虑，TTFT 可见，符合"确定感" |
| **追问** | 卡片底部原位单行输入 `[追问本段细节...]`，答复追加在卡片流内 | 跳转新会话 | 上下文连续，多轮深入不丢线索 |

## 3. 详细字段与业务规则约束矩阵 (Specifications & Constraints)

| 字段/参数名 | 披露层级 | 类型 | 必填 | 校验规则与边界极端值 | 默认值与微文案提示 |
|---|---|---|---|---|---|
| `template` | 卡片头部 | 枚举 | 是 | `general`/`logic`/`critical`/`term` | — |
| `ttft_ms` | 卡片头部 mono | 整数 | 是 | ≥ 0；`tabular-nums` | — |
| `stream_state` | 内部 | 枚举 | 是 | `idle`/`streaming`/`done`/`fallback`/`error` | idle |
| `follow_up_text` | 首屏可见 | 字符串 | 否 | 1–500 字符；空则禁用发送 | 追问本段细节...（占位符） |
| `degraded` | 卡片角标 | 布尔 | 是 | true 表示离线启发式降级 | false |
| `saved_as_note` | 内部 | 布尔 | 是 | 防止重复归档 | false |

### 业务分支规则矩阵
1. **分支 1（在线成功）**：请求下发 → 首个 token 到达即置 `streaming` 并记录 TTFT → 逐字追加 → `done`。
2. **分支 2（网络失败/超时）**：指数退避重试 N 次后进入 `fallback`，给出本地启发式摘要并标注"离线降级"。
3. **分支 3（原位追问）**：追加至同一卡片流，保持上下文连续；追问输入为空时按钮禁用。
4. **分支 4（存为边注）**：将卡片内容（含模板标签）写入 FEAT-007 边注，标注已归档，禁止重复。
5. **分支 5（收起/切换模板）**：关闭卡片不中断后台流（可选续看）；切换模板以新卡片承接同一选区。

### 4.2 行为驱动产品验收场景 (Gherkin Scenarios)

```gherkin
Feature: 流式认知伴读卡片与原位追问

  Scenario: REQ-001 点击模板流式输出伴读 (Happy Path)
    Given 用户已划选一段文本且已配置可用 LLM
    When 用户点击「逻辑」
    Then 卡片在 800ms 内开始逐字流式输出逻辑链解读
    And 卡片头部显示「逻辑链推理 · TTFT xxxms」

  Scenario: REQ-003 卡片内原位追问 (Happy Path)
    Given 伴读卡片已输出内容
    When 用户在底部「追问本段细节...」输入问题并提交
    Then 答复以流式追加在同一卡片流内，上下文保持连续

  Scenario: REQ-005 网络失败降级 (Error Recovery)
    Given 网络不可达或 LLM 端点超时
    When 用户点击「通俗」
    Then 系统指数退避重试后切换为本地启发式摘要
    And 卡片标注「离线降级」角标，不出现空白等待屏

  Scenario: REQ-004 一键存为边注幂等 (Validation)
    Given 卡片已有内容
    When 用户连续两次点击「存为边注」
    Then 仅写入一条边注，第二次点击提示「已归档为边注」
```
